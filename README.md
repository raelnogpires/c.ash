# [c]ash

## o projeto

[c]ash será um aplicativo desktop para controle financeiro pessoal.
precisamos ter um dashboard para visualização total de gastos e custos, áreas para inserção de gastos e custos fixos, entrada de renda, etc.
esse aplicativo deve ser o sistema absoluto para controle financeiro pessoal.
rodará localmente com armazenamento local de todas as informações inputadas.
personalização básica ao abrir, perguntar nome do usuário e deixar uma saudação no dashboard tipo "Olá, {user}"

## a stack

será desenvolvido em golang, trazendo compatibilidade entre windows, macos e linux. além de ser uma linguagem simples e rápida.
